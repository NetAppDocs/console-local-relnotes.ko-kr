==== Kubernetes 워크로드 개선 사항

이번 릴리스에서 NetApp Backup and Recovery는 Kubernetes 워크로드에 대해 다음과 같은 향상된 기능을 제공합니다:

* *디스크 간 백업 아키텍처를 사용한 Amazon FSx for NetApp ONTAP 지원*: 이제 동일한 AWS 리전 또는 다른 AWS 리전에서 Amazon FSx for NetApp ONTAP을 기본 스토리지로, 다른 FSx for NetApp ONTAP 파일 시스템을 2차 스토리지로 사용하는 디스크 간 백업 아키텍처를 활용하여 Kubernetes 보호 정책을 생성할 수 있습니다. 또한 Cloud Volumes ONTAP을 기본 스토리지로, FSx for NetApp ONTAP을 2차 스토리지로 사용할 수도 있습니다.
* *qtree 복원 문제 수정*: 이전에는 ontap-nas-economy 볼륨 복원 시 qtree 디렉터리의 소유자 및 권한이 잘못 복원되는 문제가 있었습니다. 이번 릴리스에서 이 문제가 해결되었습니다.


Kubernetes 보호 정책 생성에 대한 자세한 내용은 다음을 참조하십시오 https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-policies-kubernetes-create.html["NetApp Backup and Recovery에서 Kubernetes 백업 정책을 생성하고 관리합니다."^].

Kubernetes 워크로드 보호에 대한 자세한 내용은 https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-kubernetes-protect-overview.html["NetApp Backup and Recovery를 사용하여 Kubernetes 워크로드를 보호하는 방법에 대해 알아보십시오."^]을 참조하세요.



==== ONTAP Volumes 워크로드 개선 사항

이번 릴리스에서 NetApp Backup and Recovery는 ONTAP Volumes 워크로드에 다음과 같은 향상된 기능을 제공합니다:

* *복원 인터페이스 개선*: ONTAP 볼륨용 복원 마법사의 레이아웃이 새롭게 바뀌고 탐색 기능이 향상되었습니다:
+
** *향상된 선택 테이블*: 선택 테이블에 한 번에 더 많은 행과 열이 표시됩니다. 복원 화면은 간격과 이동 경로 표시를 개선하여 워크플로우에서 현재 위치를 확인할 수 있습니다.
** *단계별 탐색*: *다음* 및 *계속* 버튼 기능이 개선되어 실수로 다음 주요 단계로 건너뛰는 것을 방지합니다. *이전* 버튼을 누르면 마지막으로 완료한 화면으로 돌아가며 이전 선택 사항이 유지되므로 단계를 다시 시작할 필요가 없습니다.
** *소스 볼륨 선택 시 더 자세한 정보 표시*: 이제 볼륨 목록에 볼륨 유형, 볼륨 스타일, SnapLock 유형, 기존 보호 및 보호 상태가 표시됩니다. 기존 보호 열이 더 넓어져 모든 보호 표시기(스냅샷, 복제 및 백업)를 확인할 수 있습니다.


* *Azure 중국 리전에 호스팅된 볼륨 보호 지원*: 이제 ONTAP 볼륨을 Azure 중국(21Vianet)의 Azure Blob 스토리지에 백업할 수 있습니다. 이 지원은 Cloud Volumes ONTAP과 온프레미스 ONTAP 시스템 모두에 적용됩니다. 상용 Azure 및 Azure 정부 리전은 변경되지 않았습니다.


ONTAP Volumes 워크로드 보호에 대한 자세한 내용은 https://docs.netapp.com/us-en/data-services-backup-recovery/prev-ontap-protect-overview.html["NetApp Backup and Recovery를 사용한 ONTAP 볼륨 보호에 대해 알아보십시오"^]를 참조하십시오.

==== Kubernetes 워크로드 개선 사항

이번 릴리스에서 NetApp Backup and Recovery는 Kubernetes 워크로드에 대해 다음과 같은 향상된 기능을 제공합니다:

* *Trident Protect 26.10*: 이번 릴리스에는 Trident Protect 26.10가 포함되어 있습니다.
* *ontap-nas-economy 및 ontap-san-economy 드라이버 지원*: 이제 NetApp Trident `ontap-nas-economy` 드라이버(Qtree) 및  `ontap-san-economy` 드라이버(LUN)로 프로비저닝된 영구 볼륨 클레임(PVC)을 보호할 수 있습니다. 이코노미 드라이버를 사용하여 PVC를 보호하면 기본 FlexVol 또는 LUN 전체가 보호됩니다. 이러한 백업에서 개별 PVC를 복원할 수 있습니다.
* *Kubernetes 인식 알림*: 이제 알림이 볼륨당 한 번이 아닌 Kubernetes 애플리케이션당 한 번 전송됩니다.
* *볼륨 그룹 스냅샷 지원*: 이제 Kubernetes 애플리케이션을 정의할 때 볼륨 그룹을 생성할 수 있습니다. 볼륨 그룹을 사용하면 여러 볼륨을 함께 스냅샷하여 크래시 일관성을 유지하는 세트를 만들 수 있으므로 그룹 내 모든 볼륨에서 데이터 일관성을 보장합니다.
* *S3 호환 오브젝트 스토리지 지원*: 이제 백업 대상 자격 증명을 추가하고 보호 정책을 구성하여 Kubernetes 애플리케이션 리소스 및 데이터를 S3 호환 오브젝트 스토리지에 백업할 수 있습니다.


Kubernetes 워크로드 보호에 대한 자세한 내용은 https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-kubernetes-protect-overview.html["NetApp Backup and Recovery를 사용하여 Kubernetes 워크로드를 보호하는 방법에 대해 알아보십시오."^]을 참조하세요.



==== ONTAP Volumes 워크로드 개선 사항

이번 릴리스에서 NetApp Backup and Recovery는 ONTAP Volumes 워크로드에 다음과 같은 향상된 기능을 제공합니다:

* *보호 보고서*: NetApp Backup and Recovery는 이제 ONTAP Volumes 워크로드에 대한 확장 보고서 생성 및 다운로드를 지원합니다.
* *ONTAP 시스템 등록 해제 시 백업 유지*: NetApp Backup and Recovery에서 ONTAP 시스템 등록을 해제할 때, 이전에 백업한 데이터를 삭제할지 또는 복원용으로 유지할지 선택할 수 있습니다. NetApp Backup and Recovery 설명서에는 시스템 등록 해제 후 유지된 데이터를 복원하기 위해 ONTAP CLI를 사용하는 방법에 대한 지침이 포함되어 있습니다.


더 자세한 내용은 다음을 참조하십시오 https://docs.netapp.com/us-en/data-services-backup-recovery/prev-ontap-backup-manage.html#unregister-netapp-backup-and-recovery-for-a-system["시스템에 대한 Backup and Recovery 등록 해제"^].

ONTAP Volumes 워크로드 보호에 대한 자세한 내용은 https://docs.netapp.com/us-en/data-services-backup-recovery/prev-ontap-protect-overview.html["NetApp Backup and Recovery를 사용한 ONTAP 볼륨 보호에 대해 알아보십시오"^]를 참조하십시오.

==== 일반 NetApp Backup and Recovery 기능 향상

이번 릴리스에서 NetApp Backup and Recovery는 모든 워크로드에 대해 다음과 같은 라이선스 개선 사항을 도입했습니다:

==== Hyper-V 워크로드 개선 사항

* *NetApp MetroCluster 지원*: 이제 NetApp Backup and Recovery를 사용하여 NetApp MetroCluster로 미러링된 Hyper-V VM을 보호할 수 있습니다.
* *SAN VM용 스패닝 디스크 보호*: CIFS 및 SAN 구성의 경우, 이제 보호 그룹의 각 VM에 연결된 모든 디스크를 보호할 수 있습니다. 여기에는 여러 ONTAP 볼륨 또는 ONTAP 스토리지 시스템에 분산된 파일(스패닝 디스크)과 단일 위치로 제한된 파일이 포함됩니다.


Hyper-V 워크로드 보호에 대한 자세한 내용은 https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-hyperv-protect-overview.html["NetApp Backup and Recovery를 사용하여 Hyper-V 워크로드를 보호하는 방법에 대해 알아보십시오."]를 참조하십시오.

==== ONTAP Volumes 워크로드 개선 사항

이번 릴리스에서 ONTAP Volumes 워크로드는 다음과 같은 미리 보기 개선 사항을 도입합니다.

* *다크 사이트 지원 강화*: NetApp Backup and Recovery for dark sites는 이제 NetApp Backup and Recovery와 동일한 ONTAP Volumes 데이터 보호 기능을 제공합니다. 이 개선 사항에는 업데이트된 백업, 복원 및 작업 관리 서비스와 새로운 메타데이터 데이터베이스가 포함됩니다. 업그레이드 시 기존 데이터베이스 데이터는 자동으로 보존되고 마이그레이션됩니다. 업그레이드 후 감사 로그를 검토하여 마이그레이션이 성공적으로 완료되었는지 확인하십시오. NetApp Backup and Recovery for dark sites는 ONTAP Volumes 워크로드만 지원합니다.
* *볼륨 복원 작업 취소*: 이제 작업 모니터링 페이지에서 진행 중인 ONTAP 볼륨 복원 작업을 취소할 수 있어, 실행 시간이 길거나 속도가 느린 작업을 더욱 쉽게 관리할 수 있습니다.
* *볼륨 인덱싱 상태 보고 기능 개선*: ONTAP Volumes 대시보드는 이제 인덱싱 대상이 아닌 볼륨 및 스냅샷 복사본에 대해 `Not Applicable` 상태를 도입하여 인덱싱 상태를 더욱 정확하게 보고합니다.  `Not Indexed` 상태는 이제 인덱싱 대기 중인 볼륨에만 사용되며, 볼륨 세부 정보에서는 스냅샷별 인덱싱 상태와 함께 볼륨 또는 스냅샷 복사본이 인덱싱되지 않는 이유를 설명하는 마우스 오버 텍스트가 표시됩니다.
* *NetApp AFX 지원*: 이제 2노드 및 4노드 NetApp AFX 클러스터에서 호스팅되는 볼륨을 보호할 수 있습니다.


ONTAP Volumes 워크로드 보호에 대한 자세한 내용은 https://docs.netapp.com/us-en/data-services-backup-recovery/prev-ontap-protect-overview.html["NetApp Backup and Recovery를 사용한 ONTAP 볼륨 보호에 대해 알아보십시오"]를 참조하십시오.



==== Kubernetes 워크로드 개선 사항

이번 릴리스에서 Kubernetes 워크로드는 다음과 같은 개선 사항을 도입했습니다.

* *Trident Protect 26.09*: 이번 릴리스에는 Trident Protect 26.09가 포함되어 있습니다.
* *클러스터 및 네임스페이스 수준의 역할 기반 액세스 제어(RBAC)*: Kubernetes 클러스터 검색 중에 새 클러스터와 연결할 프로젝트 또는 폴더를 선택하여 리소스에 대한 액세스를 제어할 수 있습니다. 특정 네임스페이스를 등록하여 액세스 제어를 수행할 수도 있습니다. 이를 통해 클러스터 또는 네임스페이스 수준에서 더욱 세밀한 액세스 제어가 가능합니다.
* *파일 및 폴더 복원*: 이제 Kubernetes VM 기반 애플리케이션 백업에서 특정 파일 및 폴더를 복원하거나 다운로드할 수 있습니다.


Kubernetes 워크로드 보호에 대한 자세한 내용은 https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-kubernetes-protect-overview.html["NetApp Backup and Recovery를 사용하여 Kubernetes 워크로드를 보호하는 방법에 대해 알아보십시오."]을 참조하세요.

==== 일반 NetApp Backup and Recovery 기능 향상

이번 릴리스에서는 KVM, Hyper-V 및 VMware 워크로드에 다음과 같은 개선 사항이 도입되었습니다.

*VM 호스트 검색 중 자격 증명 선택*: KVM, Hyper-V 또는 VMware 호스트를 검색할 때 Backup and Recovery에 이미 추가한 자격 증명을 사용할 수 있습니다.



==== Hyper-V 워크로드 향상

이번 릴리스에서 Hyper-V 워크로드는 다음과 같은 개선 사항을 도입했습니다.

*VM에 대한 디스크 보호 기능 확장*: CIFS 구성의 경우, 백업 및 복구 기능은 이제 보호 그룹에 속한 각 VM에 연결된 모든 디스크를 보호할 수 있도록 지원합니다. 여기에는 여러 ONTAP 볼륨 또는 ONTAP 스토리지 시스템(스패닝 디스크)에 분산된 파일과 단일 위치에만 있는 파일이 모두 포함됩니다.

Hyper-V 워크로드 보호에 대한 자세한 내용은 https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-hyperv-protect-overview.html["NetApp Backup and Recovery를 사용하여 Hyper-V 워크로드를 보호하는 방법에 대해 알아보십시오."]를 참조하십시오.



==== ONTAP Volumes 워크로드 향상

이번 릴리스에서 ONTAP Volumes 워크로드는 다음과 같은 미리 보기 개선 사항을 도입합니다.

*일일 백업 데이터 전송 보고서*: NetApp Backup and Recovery for Volumes에 이제 보고서 탭에서 이용 가능한 일일 백업 데이터 전송 보고서가 포함되어 있어 환경 전반의 일일 백업 및 복제 데이터 전송 활동을 확인할 수 있습니다. 전체 계정 또는 선택한 스토리지 시스템에 대한 보고서를 생성하고, 날짜 범위 및 보호 유형별로 필터링한 후 CSV 파일로 다운로드할 수 있습니다.

ONTAP Volumes 워크로드 보호에 대한 자세한 내용은 https://docs.netapp.com/us-en/data-services-backup-recovery/prev-ontap-protect-overview.html["NetApp Backup and Recovery를 사용한 ONTAP 볼륨 보호에 대해 알아보십시오"]를 참조하십시오.
